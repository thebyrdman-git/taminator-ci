## Installation

### Linux (AppImage)
```bash
# Download from GitLab CEE (VPN required)
chmod +x Taminator-2.1.2.AppImage
./Taminator-2.1.2.AppImage
```

### macOS (DMG)
```bash
# Download from GitLab CEE (VPN required)
open Taminator-2.1.2.dmg
# Drag to Applications
# First run: Right-click → Open
```
