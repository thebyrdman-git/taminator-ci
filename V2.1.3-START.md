## 📝 Technical Approach

### Option A: Copy Existing Binary (Simplest)
```yaml
# In .github/workflows/release.yml
- name: Copy backend binary
  run: |
    mkdir -p gui/backend
    cp bin/tam-rfe gui/backend/
```

Then update package.json:
```json
{
  "extraResources": [
    {
      "from": "backend/tam-rfe",
      "to": "bin/tam-rfe"
    }
  ]
}
```

### Option B: Build Fresh with PyInstaller
Build backend in CI/CD instead of copying:
```yaml
- name: Build Python Backend
  run: |
    pip install pyinstaller
    pyinstaller --onefile bin/tam-rfe -n tam-rfe
    cp dist/tam-rfe gui/backend/
```

**Recommendation:** Start with Option A (copy existing) - it's faster and the binary already works.
