Let's Get You Set Up

Taminator helps Red Hat TAMs automate their workflow by tracking RFEs and Bugs, keeping customer reports up-to-date, and publishing to the portal in one click.

  • Track RFEs and Bugs automatically
  • Keep customer reports always up-to-date
  • Publish reports to portal in one click
  • Save hours of manual JIRA work each week
📋 This setup takes about 5 minutes

You'll need a JIRA API token (we'll show you how to get one)

Choose Your Authentication Method

Taminator needs to connect to JIRA and the Customer Portal. Choose how you'd like to manage your authentication tokens:

🏢 Team Setup Recommended

Use HashiCorp Vault for centralized token management

  • Centralized token management
  • Share tokens with your team
  • No token expiration issues
  • Requires Vault server access

👤 Personal Setup

Configure tokens directly in Taminator

  • Quick to set up
  • No external dependencies
  • Tokens stored locally on this computer
  • Need to update tokens when they expire

HashiCorp Vault is a centralized secrets management system. Your team admin should provide these connection details.

Example: https://vault.mycompany.com:8200

👤 Configure API Tokens

Enter your JIRA and Customer Portal API tokens. You'll need to generate these from each service.

🔑 How to Get Tokens

JIRA Personal Access Token:
1. Go to issues.redhat.com
2. Click your avatar (top right) → Profile → Personal Access Tokens
3. Click "Create token" → Name it (e.g., "Taminator Integration")
4. Set expiry date → Create → Copy immediately (won't be shown again!)

Customer Portal Offline Token:
Go to access.redhat.com/management/api → Generate offline token

Create at issues.redhat.com → Profile → Personal Access Tokens
Generate an offline token at access.redhat.com/management/api
