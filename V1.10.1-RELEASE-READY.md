## 🐛 Bugs Fixed in v1.10.1

### 1. Critical: CLI Binary Not Bundled
**Issue:** GUI failed with `spawn tam-rfe ENOENT` on systems without Python dev environment

**Root Cause:**
- Python source bundled but dependencies (rich, requests, etc.) were not
- GUI expected `tam-rfe` in system PATH
- Users without Python packages → broken GUI

**Fix:**
- Created standalone PyInstaller binary (19MB)
- Includes Python 3.9 + all dependencies
- GUI smart detection: bundled binary → Python source → system PATH
- Zero external dependencies required

**Files Changed:**
- `build-cli.spec` - PyInstaller configuration
- `build-cli-binary.sh` - Build automation
- `gui/main.js` - Smart CLI detection
- `gui/package.json` - Bundle binary
- `.github/workflows/build.yml` - Build binary first

### 2. Minor: Hardcoded Email in JIRA Auth
**Issue:** Dashboard used hardcoded `jbyrd@redhat.com` for JIRA authentication

**Fix:**
- Now uses `JIRA_USERNAME` environment variable
- Falls back to `user@redhat.com` if not set
- Portable across TAM users

**Files Changed:**
- `src/taminator/commands/dashboard.py:150`
